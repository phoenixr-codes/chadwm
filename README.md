# phoenixR fork of [chadwm][]

## Installation

```console
git clone https://github.com/phoenixr-codes/chadwm.git ~/.config/chadwm
cd ~/.config/chadwm/chadwm
sudo make install
```

## Dependencies

- `nu`
- [`xx`](https://github.com/phoenixr-codes/dotfiles/blob/b33f17f0f601f541d77bb0fa306a4e39f8ed3e53/eggs/nushell/xx.nu)
- `kitty`
- `eww` (optional)
- `maim` (optional)
- `dm-tool` (optional)
- `rofi` (optional)
- `zathura` (optional)

[chadwm]: https://github.com/siduck/chadwm
